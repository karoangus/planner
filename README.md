# برنامهٔ مطالعه و تفریح

وب‌اپ ساده و بدون وابستگی برای برنامه‌ریزی هفتگی زمان مطالعه و بودجهٔ تفریح (PWA قابل نصب روی گوشی).

- `index.html` — کل برنامه (HTML/CSS/JS)
- `manifest.webmanifest`, `sw.js`, `icon-*.png`, `icon.svg` — فایل‌های PWA

برای اجرا کافی است `index.html` را در مرورگر باز کنید. برای نصب روی گوشی، فایل‌ها را روی یک هاست استاتیک (مثل GitHub Pages) قرار دهید و از منوی مرورگر «افزودن به صفحهٔ اصلی» را بزنید.
