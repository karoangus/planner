# برنامهٔ مطالعه و تفریح

وب‌اپ بدون وابستگی برای برنامه‌ریزی هفتگی زمان مطالعه و بودجهٔ تفریح (PWA قابل نصب روی گوشی).

## امکانات
- ۹ بخش مستقل (شنبه تا چهارشنبه + پنجشنبه/جمعه در دو حالت عادی و آزمون)
- ورودی‌های ساختاریافتهٔ «حداقل / حداکثر» با دکمه‌های ± (گام ۱۵ دقیقه)، تایپ مستقیم و کلیدهای جهت‌دار
- نمایش خودکار بازهٔ خوانا به فارسی («۲ تا ۲٫۵ ساعت») و نوار بصری
- فیلتر «همه / هفتهٔ عادی / هفتهٔ آزمون» و جمع هفتگی مطالعه و تفریح
- ذخیرهٔ خودکار در LocalStorage، پشتیبان JSON (دریافت/وارد کردن)، بازنشانی کلی و تک‌روز با «بازگردانی»
- خروجی PDF/چاپ A4 راست‌چین با تاریخ شمسی و جدول جمع هفتگی
- تم تیره/روشن، کپی/اشتراک‌گذاری متن برنامه، میان‌برهای Ctrl+P و Ctrl+S
- PWA: نصب روی دستگاه، کار آفلاین، اعلان به‌روزرسانی

## فایل‌ها
- `index.html` — کل برنامه (HTML/CSS/JS)
- `manifest.webmanifest`, `sw.js`, `icon-*.png`, `icon.svg` — فایل‌های PWA

برای اجرا کافی است `index.html` را در مرورگر باز کنید. برای نصب روی گوشی، فایل‌ها را روی یک هاست استاتیک HTTPS (مثل GitHub Pages) قرار دهید.
